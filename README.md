# Финансовое мышление С4% — бланк игрока для игры «Денежный поток» (PWA)

> Неофициальный помощник. «CASHFLOW®» — товарный знак CASHFLOW Technologies; приложение с ними не связано. Для личного некоммерческого использования: коммерческое использование (в т.ч. платные игры и тренинги с этим приложением) требует разрешения правообладателя.

Устанавливается на рабочий стол смартфона как обычное приложение. Игрок регистрируется (email + пароль), присоединяется к игре по коду, заполняет бланк, а приложение копит его статистику по всем играм. Организатор игры видит бланки всех игроков своего стола, таблицу и итоги.

## Возможности
- Регистрация и вход (Supabase Auth), личная статистика: игры, победы, выходы на скоростную дорожку, ходов до выхода, лучший пассивный доход и чистая стоимость, график.
- Бланк по официальным правилам: стартовые деньги (поток + сбережения), расчётный чек, «Всякая всячина» (обязательна; при нехватке денег автоматически берётся кредит банка кратно 1000), благотворительность (3 хода с двумя кубиками), увольнение (платёж расходов + пропуск 2 ходов), дети (до 3), кредиты кратно 1000 по $100/мес за $1000, погашение прочих долгов только полностью, продажа активов с пометкой «только по карточке Рынок/при банкротстве», дробление акций, ROI.
- Банкротство: триггер при отрицательном потоке без денег, продажа банку за ½ взноса, сокращение долгов вдвое, пропуск 3 ходов, выбытие.
- Выход на скоростную дорожку: получение стартового дохода ×100, Мечта (цена растёт на 100% за жетон соперника), предприятия, налоговая проверка, развод, судебный иск; победа — Мечта или +$50 000 к доходу; организатору показывается, кто выиграл первым.
- Счётчик ходов, отмена последнего действия, ручная правка наличных с обязательной причиной (организатор видит число правок), отчёт для разбора (текст для наставника/ИИ).
- Режим «Мой реальный кэш-флоу» (₸/$/₽/€), не попадает в игровую статистику.
- Организатор: код игры, стол в реальном времени, бланк любого игрока (только чтение), «Итоги игры», завершение игры.

## Запуск за 10 минут

### 1. Supabase (бесплатно)
1. Создайте проект на https://supabase.com (регион ближе к игрокам).
2. SQL Editor → New query → вставьте весь файл `supabase.sql` → Run.
3. Authentication → Providers → Email: «Confirm email» можно оставить включённым (игрок подтвердит почту по ссылке) или отключить для быстрого старта.
4. Authentication → URL Configuration: в «Site URL» и «Redirect URLs» впишите адрес приложения на GitHub Pages (из шага 3 ниже). Без этого ссылки из писем (подтверждение почты, восстановление пароля) не вернут игрока в приложение.
5. Project Settings → API: скопируйте `Project URL` и `anon public` key.

### 2. Настройка приложения
Откройте `config.js` и впишите:
```js
window.CFG = { SUPABASE_URL: 'https://xxxx.supabase.co', SUPABASE_ANON_KEY: 'eyJ...' };
```
anon-ключ публичный, его можно хранить в репозитории: данные защищены правилами доступа (RLS) из `supabase.sql`. Никогда не публикуйте `service_role` ключ.

### 3. Публикация на GitHub Pages
1. Загрузите файлы в репозиторий GitHub.
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту приложение откроется по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

### 4. Установка на смартфон
- Android (Chrome): меню ⋮ → «Установить приложение» (или кнопка «📲 Установить» на главной).
- iPhone (Safari): «Поделиться» → «На экран „Домой“».

## Регистрация, профиль, рассылка
- При регистрации: имя и фамилия, никнейм (необязательно), как показывать (имя или никнейм), телефон WhatsApp, галочка «Хочу получать информацию и новости о проекте C4%» (по умолчанию не отмечена).
- Другим игрокам и на экране «Итоги игры» показывается то, что выбрал игрок. Организатор в таблице и в бланке игрока видит и имя, и никнейм.
- Телефон и согласие хранятся в таблице `profiles`. Организаторы игр их не видят; вы как владелец проекта открываете Supabase → Table Editor → profiles и фильтруете `news = true` для рассылки. Игрок может изменить данные и снять согласие в разделе «Профиль».
- Восстановление пароля: на экране входа «Забыли пароль?» → письмо со ссылкой → новый пароль.

## Список профессий
В приложение встроены 12 профессий с карточек игры (водитель грузовика, менеджер, автомеханик, дворник, пилот авиалиний, инженер, секретарь, врач, офицер полиции, учитель, адвокат, медсестра). Цифры сверены с фотографиями каждой карточки. Исправленная игроком и сохранённая в список профессия заменяет встроенную.

Когда игрок заполнил карточку (профессия и данные) и сделал первый ход, карточка автоматически попадает в общий список. Остальные игроки выбирают профессию кнопкой «Выбрать профессию из списка» до первого хода, и бланк заполняется сам. Можно сохранить карточку вручную кнопкой «Сохранить профессию в список». Названия профессий уникальны. Удалять и править профессии может автор записи (или вы через Table Editor → professions).

## Победа и выход на скоростную дорожку
- Игра не заканчивается автоматически. Когда условия победы выполнены (куплена Мечта или доход вырос на $50 000), приложение спрашивает «Закончить игру?». «Отмена» — игра продолжается, закончить можно кнопкой «🏆 Закончить игру победой».
- Перед выходом на скоростную дорожку приложение показывает оставшиеся долги. Организатор в экране игры выбирает правило стола: долги гасить не обязательно / погасить кредит банка / погасить все кредиты и долги.
- Если вышли по ошибке — кнопка «↩ Отменить выход» возвращает бланк к состоянию на момент выхода.

## Рейтинг и достижения
На главной: «Мои достижения» (значки) и «Рейтинг игроков» — «Мои столы» (игры, где вы играли или были организатором) и «Все игроки», за всё время или за месяц. Очки: участие 1, выход на скоростную дорожку 3, победа 5, первым победил за столом +2. Игрок может скрыть себя из рейтинга в «Профиле».

## Сделки между игроками
В бланке есть раздел «Сделки с игроками»: «🤝 Взять / дать деньги игроку» → выбрать игрока стола, сумму, ежемесячный платёж (проценты) и условия. Второй игрок видит предложение у себя и подтверждает или отклоняет. После подтверждения деньги автоматически переходят, у заёмщика появляется долг и расход, у кредитора — заём (актив) и пассивный доход. Возврат («Вернуть» / «Мне вернули») тоже подтверждает второй игрок; кредитор может «Простить» долг. Организатор видит сделки в бланках игроков.
В официальных правилах займы между игроками прямо не описаны (разрешена продажа права на сделку по карточке) — это правило стола, договоритесь о нём до начала игры. Ежемесячные платежи учитываются в расчётном чеке на крысиных бегах; на скоростной дорожке переходят только сами деньги.

## Как играть
1. Организатор: «Организовать игру» → получает код → сообщает его столу. Может играть сам кнопкой «Играть самому».
2. Игроки: регистрируются → «Присоединиться по коду» → вводят данные с карточки профессии.
3. В конце организатор нажимает «Завершить игру» и открывает «Итоги игры».

## Конфиденциальность
- Игрок видит только свой бланк. Организатор видит бланки игроков только своих игр.
- Список игр наружу не отдаётся: игру можно найти только по точному коду (функция `find_game`), присоединиться можно только к открытой игре.
- Регистрация требует обязательного согласия на обработку персональных данных. Текст в приложении — ШАБЛОН: согласуйте его с юристом (закон РК «О персональных данных и их защите») и впишите оператора.

## Файлы
- `index.html`, `style.css`, `app.js` — приложение
- `config.js` — ключи Supabase
- `supabase.sql` — таблицы и правила доступа
- `manifest.webmanifest`, `sw.js`, `icons/` — установка на рабочий стол и офлайн-оболочка

## Важно после обновления
Выполните `supabase.sql` заново целиком (он безопасен при повторном запуске): добавляются функции доступа, новые правила и поле согласия.

## Ограничения
- Приложение не проверено на реальном Supabase и телефонах автором сборки — сначала пройдите игру на тестовом столе.
- Без интернета бланк открывается, но изменения не сохраняются в облако (в приложении видна пометка «Нет связи»).
- Карточки «Рынок/Возможность» и колоды в приложении не встроены: игрок вносит данные с карточек сам. Приложение подсказывает правила, но не заменяет ведущего.
